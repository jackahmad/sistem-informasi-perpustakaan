# sistem-informasi-perpustakaan
Dokumentasi Sistem Informasi Perpustakaan yang membahas kebutuhan jaringan komputer, komunikasi data, serta komponen pendukung untuk pengelolaan data buku dan transaksi peminjaman.

# Sistem Informasi Perpustakaan

## Deskripsi
Sistem Informasi Perpustakaan merupakan sistem yang digunakan untuk mengelola data buku, data anggota, peminjaman, dan pengembalian buku secara terkomputerisasi.

## Tujuan
- Mempermudah pencarian informasi buku.
- Mempermudah pengelolaan data anggota.
- Membantu pencatatan transaksi peminjaman dan pengembalian.
- Meningkatkan efisiensi pelayanan perpustakaan.

## Dokumentasi
Folder `Dokumentasi` berisi dokumen pendukung mengenai kebutuhan jaringan komputer dan komunikasi data dalam Sistem Informasi Perpustakaan.

## Teknologi Pendukung
- Jaringan LAN dan Wi-Fi.
- Aplikasi berbasis web.
- Server dan basis data.

  
Untuk mendukung Sistem Informasi Perpustakaan, diperlukan jaringan komputer yang
menghubungkan perangkat petugas, komputer pengguna, dan server agar pengelolaan data
buku serta transaksi peminjaman dapat berjalan dengan baik.

1. Perangkat pengguna/client Komputer atau laptop yang digunakan oleh petugas perpustakaan
untuk mengelola data buku, mencatat peminjaman dan pengembalian, serta perangkat
pengguna untuk mencari informasi dan ketersediaan buku.
2. Server Komputer server yang berfungsi menyimpan dan mengelola database perpustakaan,
seperti data buku, data anggota, serta riwayat peminjaman dan pengembalian.
3. Media koneksi jaringan Kabel LAN (Ethernet) digunakan untuk menghubungkan komputer
dengan jaringan secara stabil, sedangkan Wi-Fi digunakan untuk perangkat yang membutuhkan
koneksi tanpa kabel.
4. Perangkat jaringan yang diperlukan
• Router: menghubungkan jaringan lokal ke Internet.
• Switch: menghubungkan beberapa komputer dan server dalam jaringan lokal.
• Access point: menyediakan koneksi Wi-Fi bagi laptop atau perangkat pengguna.
5. Akses jaringan yang digunakan LAN (Local Area Network) digunakan untuk menghubungkan
komputer petugas dan server di lingkungan perpustakaan. Sementara itu, Internet digunakan jika
sistem ingin diakses secara online oleh mahasiswa atau anggota perpustakaan dari luar area
perpustakaan.
Kesimpulan: Kebutuhan jaringan tersebut mendukung Sistem Informasi Perpustakaan agar
pengelolaan data buku, anggota, dan transaksi peminjaman dapat dilakukan secara cepat,
terintegrasi, dan efisien

1. Data dari pengguna ke aplikasi dan server Pengguna memasukkan data seperti nama pengguna,
kata sandi, kata kunci pencarian buku, data anggota, serta permintaan peminjaman dan
pengembalian buku.
2. Data dari aplikasi ke server Aplikasi mengirimkan permintaan untuk mencari data buku, memeriksa
ketersediaan buku, memvalidasi akun anggota, serta menyimpan transaksi peminjaman dan
pengembalian ke database.
3. Data dari server ke aplikasi Server mengirimkan hasil pencarian buku, informasi ketersediaan buku,
data anggota, status peminjaman, serta informasi tanggal pengembalian.
4. Informasi dari aplikasi ke pengguna Aplikasi menampilkan informasi yang dibutuhkan pengguna,
seperti daftar buku, lokasi buku, status ketersediaan, konfirmasi peminjaman, dan pemberitahuan
keterlambatan pengembalian.
